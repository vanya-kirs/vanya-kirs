# Telegram Lead Parser

Python-сервис, который помогает отделу продаж отбирать обращения из потока Telegram-сообщений. Пользователь задаёт источники и критерии поиска, а менеджер видит подходящие сообщения, оценку модели и ссылку на оригинал.

## Попробовать за минуту

Откройте терминал в папке проекта. Для демонстрации достаточно Python 3.11 или новее.

```bash
python demo.py
```

Пример обрабатывает три вымышленных сообщения через функции из рабочего сервиса. Вопрос владельца мастерской проходит первичный отбор, его повтор с другой пунктуацией распознаётся как дубль, а рекламное предложение отсеивается по стоп-фразе. Этот шаг показывает, какие сообщения попадут на оценку модели. Демонстрация работает локально без ключей и подключения к Telegram.

## Как устроена обработка

1. Telethon получает историю и новые события из источников. PostgreSQL хранит текст, идентификатор сообщения и связь с источником.
2. Сервис проверяет идентификаторы и нормализует текст. Для поиска похожих сообщений в коде предусмотрено сравнение множеств слов по коэффициенту Жаккара.
3. Фильтр по ключевым словам отбрасывает явный шум до платного обращения к модели. Клиент Claude передаёт текст на классификацию, результат затем используется для отбора лидов.
4. FastAPI предоставляет API для источников, критериев и лидов. Telegram-бот на aiogram служит интерфейсом. Фоновые задачи выполняет Celery с Redis.

## Локальная разработка

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pytest
```

## Запуск с собственными источниками

1. Скопируйте `.env.example` в `.env`. Укажите собственные API_ID и API_HASH Telegram, токен бота и ключ Anthropic. Задайте случайный SECRET_KEY (например, через `openssl rand -hex 32`).
2. В установленном окружении выполните `make generate-session` и сохраните полученный SESSION_STRING в локальном `.env`.
3. Выполните `docker compose up -d --build`. API применяет миграции при старте. Интерактивная документация доступна по адресу `http://localhost:8000/docs`, проверка состояния - `http://localhost:8000/health`.
4. В интерфейсе бота добавьте источник и настройте критерии. Для уведомлений владельцу укажите OWNER_TELEGRAM_ID. При оценке сообщений через Claude расходуется баланс вашего API-аккаунта.
